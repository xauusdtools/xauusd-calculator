# Contributing

Thanks for helping! This project aims to stay small, correct and dependency-free.

- **No runtime dependencies.** Plain ES modules that run in Node >= 18 and browsers.
- **Tests required.** Add or update cases in `test/` and run `npm test` (uses `node:test`).
- **Validate inputs** and document new functions with JSDoc.
- **Keep examples hypothetical.** No trading signals, performance claims or promotional links in code, docs or issues.
- Broker conventions differ (contract size, pip vs point). Prefer adding options over changing defaults.

Open an issue first for larger changes (e.g. Pine Script or Python ports). By contributing you agree your work is licensed under the MIT licence.
